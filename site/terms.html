You can remove DriveSync's access at any time, as the privacy policy explains.

What a two-way sync means

DriveSync copies changes in both directions: a file you change or delete on one side is changed or deleted on the other. It stops and asks before a run that would delete too many files, and it keeps a conflict copy when a file changed on both sides, but it cannot protect against every mistake or failure. Keep a separate backup of any file you cannot afford to lose.
